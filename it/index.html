Ciberarmi e Spyware sotto Indagine

Analizziamo la struttura funzionale, i domini C2 e i vettori di infezione dei principali attori del mercato dello spionaggio governativo.

NSO Group

Pegasus

Spyware in grado di estrarre messaggi, foto, chiamate e attivare microfono/fotocamera in tempo reale senza richiedere interazione della vittima.

Vector: Zero-Click iMessage
Cytrox / Intellexa

Predator

Piattaforma di spionaggio persistente che utilizza link manipolati tramite reti telefoniche o attacchi di inserimento del traffico HTTP.

Vector: One-Click / MITM
QuaDream

Reign

Strumento altamente furtivo progettato per auto-rimuovere tracce di memoria ed eludere le analisi tradizionali sui dispositivi iOS.

Vector: Calendar Invites
Exploit Zero-Day

FORCEDENTRY

Iniezione di patch di decompressione di immagini PDF/JBIG2 che emulava un'architettura logica di CPU all'interno di Apple CoreGraphics.

Tipo: CVE-2021-30860

Strumenti de Análisis Forense y Verificación Móvil

Integrazione diretta con il Mobile Verification Toolkit (MVT) di Amnesty International e gli scanner di indicatori di compromissione (IoC) sviluppati da laboratori leader come Kaspersky e Citizen Lab.

MVT (Mobile Verification Toolkit)

Analizza backup di iTunes, dump Android (ADB) e database SQLite alla ricerca di artefatti di Pegasus.

Kaspersky Triangle Check / Scanner IoC

Utility automatica per rilevare tracce dell'operazione "Operation Triangulation" nei dump del sistema operativo.

Guida Rapida all'Esecuzione di MVT Python 3.10+

# 1. Installa MVT tramite Python Package Manager

$ pip install mvt

# 2. Scarica gli ultimi IoC di Pegasus & Predator

$ mvt-ios download-iocs

# 3. Analizza backup iOS precedentemente estratto

$ mvt-ios check-backup --iocs iocs/pegasus.stix2 /path/to/backup
