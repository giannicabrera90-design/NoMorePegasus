我们分析了政府间谍活动市场中关键参与者的功能结构、C2 域以及感染载体。

NSO Group

Pegasus

能够提取消息、照片、通话记录，并可实时激活麦克风/摄像头，无需受害者任何交互的间谍软件。

攻击向量：零点击 iMessage
Cytrox / Intellexa

Predator

利用电信网络操纵链接或 HTTP 流量注入攻击的持久性间谍平台。

攻击向量：单点点击 / 中间人攻击
QuaDream

Reign

设计高度隐蔽，能够自动清除内存痕迹并规避 iOS 设备上传统分析的工具。

攻击向量：日历邀请
Exploit Zero-Day

FORCEDENTRY

通过 PDF/JBIG2 图像解压补丁注入，在 Apple CoreGraphics 内部模拟逻辑 CPU 架构的漏洞利用。

类型：CVE-2021-30860

行動取證分析與驗證工具

与国际特赦组织（Amnesty International）的移动验证工具包（MVT）以及由卡巴斯基和公民实验室等领先实验室开发的入侵指标（IoC）扫描器直接集成。

MVT（移动验证工具包）

分析 iTunes 备份、Android 转储（ADB）和 SQLite 数据库，以搜寻 Pegasus 痕迹。

Kaspersky Triangle Check / IoC 扫描器

用于在操作系统转储中自动检测“三角测量行动（Operation Triangulation）”痕迹的实用工具。

MVT 快速执行指南 Python 3.10+

# 1. 通过 Python 包管理器安装 MVT

$ pip install mvt

# 2. 下载最新的 Pegasus 和 Predator 的 IoC

$ mvt-ios download-iocs

# 3. 分析先前提取的 iOS 备份

$ mvt-ios check-backup --iocs iocs/pegasus.stix2 /path/to/backup
