ابزارهای تحلیل جرم‌شناسی و تأیید موبایل

یکپارچه‌سازی مستقیم با جعبه‌ابزار تأیید موبایل (MVT) عفو بین‌الملل و اسکنرهای شاخص‌های سازش (IoC) توسعه یافته توسط آزمایشگاه‌های پیشرو مانند کسپرسکی و سیتیزن لب.

MVT (جعبه‌ابزار تأیید موبایل)

بک‌آپ‌های iTunes، دامپ‌های اندروید (ADB) و پایگاه‌های داده SQLite را برای یافتن آثار پگاسوس تحلیل می‌کند.

بررسی مثلثی کسپرسکی / اسکنرهای IoC

ابزار خودکار برای تشخیص ردپاهای عملیات "Operation Triangulation" در دامپ‌های سیستم عامل.

راهنمای سریع اجرای MVT Python 3.10+

# ۱. نصب MVT از طریق مدیر بسته پایتون

$ pip install mvt

# ۲. دانلود آخرین IoCهای پگاسوس و پرداتور

$ mvt-ios download-iocs

# ۳. تحلیل بک‌آپ iOS از پیش استخراج شده

$ mvt-ios check-backup --iocs iocs/pegasus.stix2 /path/to/backup
