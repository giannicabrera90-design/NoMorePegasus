모바일 포렌식 분석 및 검증 도구

Amnesty International의 Mobile Verification Toolkit(MVT) 및 Kaspersky, Citizen Lab 등 선도 연구소가 개발한 침해 지표(IoC) 스캐너와의 직접 통합.

MVT (Mobile Verification Toolkit)

iTunes 백업, Android 덤프(ADB) 및 SQLite 데이터베이스를 분석하여 Pegasus 아티팩트를 찾습니다.

Kaspersky Triangle Check / IoC 스캐너

OS 덤프에서 "Operation Triangulation" 작전의 흔적을 자동으로 탐지하는 유틸리티.

MVT 빠른 실행 가이드 Python 3.10+

# 1. Python 패키지 관리자를 통해 MVT 설치

$ pip install mvt

# 2. Pegasus 및 Predator의 최신 IoC 다운로드

$ mvt-ios download-iocs

# 3. 미리 추출한 iOS 백업 분석

$ mvt-ios check-backup --iocs iocs/pegasus.stix2 /path/to/backup
