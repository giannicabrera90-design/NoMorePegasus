🛡️ NoMorePegasus Project

NoMorePegasus is a global, open, and independent initiative dedicated to raising awareness, conducting technical analysis, and providing defensive mitigation against state-grade spyware such as Pegasus, Predator, and Reign.

Project Objectives

Technical Education: Explaining the mechanics of zero-click and zero-day exploits (e.g., FORCEDENTRY) in an accessible way.
Democratization of Tools: Centralizing step-by-step usage guides for open-source forensic tools—such as the Mobile Verification Toolkit (MVT)—and various detection utilities.
Threat Intelligence: Centralizing and interpreting Indicators of Compromise (IoCs) and public command-and-control (C2) domains.
