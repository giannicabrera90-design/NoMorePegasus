NSO Group

Pegasus

Spyware, die Nachrichten, Fotos und Anrufe abgreifen sowie Mikrofon und Kamera in Echtzeit aktivieren kann, ohne dass eine Interaktion des Opfers erforderlich ist.

Vektor: Zero-Click-iMessage
Cytrox / Intellexa

Predator

Persistente Spionage-Plattform, die manipulierte Links über Telefonie-Netzwerke oder HTTP-Traffic-Einschleusungsangriffe nutzt.

Vektor: One-Click / MITM
QuaDream

Reign

Ein äußerst heimliches Tool, das entwickelt wurde, um Spuren aus dem Speicher automatisch zu löschen und herkömmliche Analysen auf iOS-Geräten zu umgehen.

Vektor: Kalendereinladungen
Exploit Zero-Day

FORCEDENTRY

Einfügen von Dekompressions-Patches in PDF/JBIG2-Bilder, die eine logische CPU-Architektur innerhalb von Apple CoreGraphics emulierten.

Typ: CVE-2021-30860

Forensische Analyse- und Mobilverifikationswerkzeuge

Direkte Integration mit dem Mobile Verification Toolkit (MVT) von Amnesty International und den von führenden Laboren wie Kaspersky und Citizen Lab entwickelten IoC-Scannern.

MVT (Mobile Verification Toolkit)

Analysiert iTunes-Backups, Android-Dumps (ADB) und SQLite-Datenbanken auf Spuren von Pegasus.

Kaspersky Triangle Check / IoC Scanners

Automatische Utility zur Erkennung von Spuren der Operation "Operation Triangulation" in Systemdumping.

MVT-Kurzanleitung Python 3.10+

# 1. MVT über den Python Package Manager installieren

$ pip install mvt

# 2. Letzte IoCs von Pegasus & Predator herunterladen

$ mvt-ios download-iocs

# 3. Analysiere iOS-Backup, das zuvor extrahiert wurde

$ mvt-ios check-backup --iocs iocs/pegasus.stix2 /path/to/backup
