Інструменти форензік-аналізу та мобільної верифікації

Пряма інтеграція з Mobile Verification Toolkit (MVT) від Amnesty International та сканерами індикаторів компрометації (IoC), розробленими провідними лабораторіями, такими як Kaspersky та Citizen Lab.

MVT (Mobile Verification Toolkit)

Аналізує резервні копії iTunes, дампи Android (ADB) та бази даних SQLite у пошуку артефактів Pegasus.

Kaspersky Triangle Check / Сканери IoC

Автоматична утиліта для виявлення слідів операції «Operation Triangulation» у дампах операційної системи.

Швидкий посібник із запуску MVT Python 3.10+

# 1. Встановити MVT через менеджер пакетів Python

$ pip install mvt

# 2. Завантажити останні IoC для Pegasus та Predator

$ mvt-ios download-iocs

# 3. Проаналізувати попередньо витягнуту резервну копію iOS

$ mvt-ios check-backup --iocs iocs/pegasus.stix2 /path/to/backup
