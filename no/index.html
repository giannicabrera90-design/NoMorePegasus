Reign

Type: CVE-2021-30860
Åpen deteksjonspakke

Verktøy for rettsmedisinsk analyse og mobil verifisering

Direkte integrasjon med Mobile Verification Toolkit (MVT) fra Amnesty International og indikatorer for kompromittering (IoC) utviklet av ledende laboratorier som Kaspersky og Citizen Lab.

MVT (Mobile Verification Toolkit)

Analyserer iTunes-sikkerhetskopier, Android-dumper (ADB) og SQLite-databaser på jakt etter Pegasus-artefakter.

Kaspersky Triangle Check / IoC-skannere

Automatisk verktøy for å oppdage spor etter operasjonen «Operation Triangulation» i operativsystem-dumper.

Hurtigstartguide for MVT Python 3.10+

# 1. Installer MVT via Python Package Manager

$ pip install mvt

# 2. Last ned nyeste IoC-er for Pegasus og Predator

$ mvt-ios download-iocs

# 3. Analyser tidligere ekstrahert iOS-sikkerhetskopi

$ mvt-ios check-backup --iocs iocs/pegasus.stix2 /path/to/backup
