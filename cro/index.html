Alati za Forenzičku Analizu i Mobilnu Verifikaciju

Izravna integracija s Mobile Verification Toolkit (MVT) Amnesty Internationala i skenerima indikatora kompromitacije (IoC) koje su razvili vodeći laboratoriji poput Kasperskyja i Citizen Laba.

MVT (Mobile Verification Toolkit)

Analizira iTunes sigurnosne kopije, Android dumpove (ADB) i SQLite baze podataka u potrazi za Pegasus artefaktima.

Kaspersky Triangle Check / IoC Skeneri

Automatski alat za otkrivanje tragova operacije "Operation Triangulation" u dumpovima operativnog sustava.

Brzi Vodič za Pokretanje MVT-a Python 3.10+

# 1. Instaliraj MVT putem Python Package Managera

$ pip install mvt

# 2. Preuzmi najnovije IoC-ove za Pegasus i Predator

$ mvt-ios download-iocs

# 3. Analiziraj prethodno ekstrahiranu iOS sigurnosnu kopiju

$ mvt-ios check-backup --iocs iocs/pegasus.stix2 /path/to/backup
