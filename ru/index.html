Инструменты криминалистического анализа и мобильной проверки

Прямая интеграция с Mobile Verification Toolkit (MVT) от Amnesty International и сканерами индикаторов компрометации (IoC), разработанными ведущими лабораториями, такими как Kaspersky и Citizen Lab.

MVT (Mobile Verification Toolkit)

Анализирует резервные копии iTunes, дампы Android (ADB) и базы данных SQLite в поисках артефактов Pegasus.

Kaspersky Triangle Check / Сканеры IoC

Автоматическая утилита для обнаружения следов операции «Operation Triangulation» в дампах операционной системы.

Краткое руководство по запуску MVT Python 3.10+

# 1. Установить MVT через менеджер пакетов Python

$ pip install mvt

# 2. Скачать последние IoC для Pegasus и Predator

$ mvt-ios download-iocs

# 3. Проанализировать предварительно извлеченную резервную копию iOS

$ mvt-ios check-backup --iocs iocs/pegasus.stix2 /path/to/backup
